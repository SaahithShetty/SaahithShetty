**Computer Vision • Transfer Learning • Production Inference**  

**The Challenge:** Deploy a multi-class image classifier (101 classes) to production with high accuracy and low latency

**My Approach:**

- Custom preprocessing pipeline for optimal inference
- Exported **SavedModel** format for production deployment

**Results:** 
- ✅ **85%+ accuracy** on test set
- ✅ Production-ready inference pipeline
- ✅ Systematic model comparison and selection

### 🧾 SkimLit — Medical Abstract Sentence Classification
**NLP • Sequential Classification • Research Replication**  

**The Challenge:** Classify sentences in medical abstracts into 5 structural categories (Background, Objective, Methods, Results, Conclusions)

**My Approach:**
- Built multimodal NLP model on **200k+ medical abstract sentences**
- Architecture: **Universal Sentence Encoder + char embeddings + positional encoding + BiLSTM**
- Replicated research paper methodology with production-grade code

**Results:**
- ✅ High classification accuracy across all 5 categories
- ✅ Handles sequential dependencies in abstract structure
- ✅ Deployable model with preprocessing pipeline

### ₿ Bitcoin Price Forecasting
**Time Series • LSTM/Conv1D • Temporal Validation**  

**The Challenge:** Forecast Bitcoin prices using historical data with proper temporal validation

**My Approach:**
- Analyzed **2,800+ daily timesteps (2013–2021)**
- Implemented sliding window approach with proper temporal splits
- Compared **LSTM, Conv1D, Dense architectures** + ensemble techniques
- Prevented data leakage with strict temporal validation

**Results:**
- ✅ Robust temporal forecasting models
- ✅ Systematic architecture comparison
- ✅ Production-ready time series pipeline
